A continuación se encuentran los pasos para que funcione nuestro chat:

1. Asegúrate de conocer la dirección IPv4 de ambas computadoras. Puedes obtener esta información ingresando al símbolo del sistema y escribiendo "ipconfig".

2. Desde la computadora 1, que actuará como servidor, abre la clase FRM1.

3. En la línea 78 de la clase FRM1, encuentra el campo entre comillas y coloca la dirección IPv4 de la segunda computadora.

4. En la segunda computadora, realiza el mismo paso que en el paso 3, pero esta vez en la clase FRM2. (Esto es para mantener coherencia entre las configuraciones.)

5. Puedes eliminar las clases FRM1 y FRM2 que no se están utilizando para evitar confusiones.

6. Finalmente, ejecuta el archivo de la clase FRM1 en la computadora 1 y el archivo de la clase FRM2 en la computadora 2.

7. Si has seguido los pasos correctamente, el chat debería iniciar correctamente.
